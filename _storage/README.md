# `_storage` 项目存储区

这个目录保存不适合进入 Git、但仍需要由外部软件同步和备份的项目文件。

- AI 生成的图片、音视频、工程文件、中间产物和其他不准备提交到 Git 的文件，默认放在这里。
- 临时文件统一放在 `_storage/temp/`。`temp` 表示文件可以在确认后清理，不表示它不需要同步或备份。
- 除本说明文件外，`_storage/` 的内容不进入 Git，由项目实际需要决定；不要预先创建统一的子目录或示例文件。
- 清理、移动或覆盖这里的文件前，应先确认项目用途和外部备份状态。

Git 只跟踪本说明文件；其余内容由项目约定的外部存储与备份工具管理。
