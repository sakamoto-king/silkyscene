# 03 · 运动角色与空对象

沿用 `silkyscene@1`：中心为 0，Y 向上，1 u = 1080 设计 px，anchor 和连线端点取 [-1, 1]。

## 1. 决策表

| 需求 | 用什么 | 为什么 |
| --- | --- | --- |
| 线端要落在一个点上，不画任何东西 | `kind: "null"` 空对象 | 没有尺寸、不出画面，替代「透明的 2 px 小盒子」 |
| 一个点跟着某个框一起动 | 把空对象和框放进同一个 `group` | 复用组的继承（位移、缩放、透明度），不另造 parent |
| 一个点驱动多条线（分叉 / 汇聚） | 所有线端都挂在同一个空对象上，再动这个空对象 | 连线逐帧实时跟随 |
| HUD 线指向世界里的物体 | screen 层一个空对象 + 世界层一个空对象，线写明 `layer` | 跨层投影只是兜底 |
| 光标、飞入的卡片、分裂、换位 | `motion: "free"`（rect、image、path、group、null 默认） | 位移默认走弧线，更像手部或物体的真实运动 |
| 框里的文字、按钮、标签、字幕条 | `motion: "bound"`（text、dots 默认） | 只做水平**或**垂直平移 + 透明度 |
| 某次移动要直线 | 节点上写 `arc: 0` | 与直线插值逐点一致 |
| 整个项目都不要弧线 | 顶层 `motion: { arc: 0 }` | 项目级默认 |

## 2. 字段

- `kind: "null"`：只有 `layout.region / x / y / anchor`，**不能**写 width / height。可放在区域、组或 screen 下；`ignoreMask: true` 进入 under 层。可被 x / y / scale 节点和 motionPath 驱动，也可作为连线端点。
- `line.layer`：`under | world | screen`。端点在别的层时投影到线所在层：world / under → screen 乘当前相机矩阵；screen → world 乘相机矩阵的逆。
- `motion`：`free | bound`。默认按类型：text、dots 为 bound，其余为 free。
- `arc`：0..1，弧线中点偏离直线弦的距离占路程的比例。默认 0.15，0 = 直线。层级：节点 > 元素 > 项目 `motion.arc` > 默认值。
- `arcSide`：`auto | left | right`，层级同上。left / right 相对运动方向（Y 向上，左即逆时针 90°）；**auto = 背离所属容器中心**（朝弦中点所在那一侧外弯），中点正好在容器中心时按 left。

## 3. 弧线公式

二次贝塞尔：`B(e) = lerp(e) + 4e(1−e) · arc · L · n`，控制点 = 中点 + 2 · arc · L · n。

- `e = ease(p)`，**速度仍由 ease 决定**；L 是路程，n 是弯曲方向的单位法向量。
- 同一元素、同一时刻、同一时长的 x 和 y 节点合成一条弧线，两者 ease 必须相同；只有一个轴时也会弯（另一轴在原值上叠加凸起）。
- 起点按接管规则取触发时刻的实际 x / y，终点保持声明值。

## 4. 不生成弧线的情况

| 参数 | 范围 | 按直线处理的情况 |
| --- | --- | --- |
| arc | [0, 1] | 元素是 bound、arc = 0、时长 0、起终点重合、x / y 用了百分比单位（显式写 arc 则报错） |
| arcSide | auto / left / right | — |
| motion | free / bound | line 不参与 |

bound 元素写 `arc`、`motionPath`，或在同一时刻同一时长同时动 x 和 y，都会报错。

## 5. motionPath：精确沿线走

```json
{ "at": "t16.00", "target": "pulse-1", "property": "motionPath", "duration": 0.9,
  "path": { "curve": "cubic", "points": [[-0.73, 0], [-0.5, 0], [-0.3, 0.3], [0, 0.3]] }, "ease": "ease-in-out" }
```

- `curve: linear | quadratic | cubic`；cubic 的点数满足 `(n − 1) % 3 = 0`，quadratic 为奇数。
- 第一个点在运行时被触发时刻的实际位置替换；按弧长近似匀速采样，缓动作用在弧长进度上。
- 让「脉冲」沿一条 `curve: "horizontal"` 的连线走：用同一个公式算控制点（样片里的 `horizontalCurve(a, b)`），点会严丝合缝地贴着线。

## 6. 检查器

- 「空对象」开关：空对象显示为斜十字。
- 「弧线」开关：画出每个 free 位移节点解算出的曲线，选中元素实线、其余虚线。
- 节点卡片列出 arc 在各级的声明值和解算值（arc、方向、中点偏移 px），不生效时注明原因。

## 7. 已知限制

- 空对象不能作为容器；要「跟随」请用 group。
- 弧线只支持 u 单位的 x / y。
- 容器（组）本身也在动时，检查器的弧线示意按当前帧容器位置绘制，与实际路径会有偏差。
- bound 的「只能水平或垂直」只检查同一时刻、同一时长的 x + y 节点对。
