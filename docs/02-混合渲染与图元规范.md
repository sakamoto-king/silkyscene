# 02 · 混合渲染与图元规范

沿用 `silkyscene@1`：中心为 0，Y 向上，1 u = 1080 设计 px，anchor ∈ [-1, 1]。`parseProject` 严格校验：本页之外的字段、类型错误、单位不一致、属性不适用于目标（如给矩形写 `zoom`），一律报错。

## 1. 渲染：DOM + SVG 混合

- 矩形、文字、图片、点阵用 HTML DOM；连线、路径用 SVG。两者共用同一套设计像素与相机矩阵，只消费解算结果。
- **三层**：
  - `world`（默认）：随相机运动，受 `canvas.worldMask` 遮罩。
  - `under`：`ignoreMask: true` 的世界层元素（如背景点阵），随相机但画在遮罩下方。
  - `screen`：HUD，不随相机；`layout.region: "screen"`（保留名，不能当区域 id）。
- `canvas.worldMask.stops[{ at, alpha }]`：`at` 取 `"-50%".."50%"`（屏幕纵向），`alpha` 0..1，线性渐变遮罩，只作用于 world 层。
- `canvas.background` 可以是颜色，也可以是 CSS 渐变（`linear-` / `radial-` / `conic-gradient(...)`）。

## 2. 图元一览

| kind | 用途 | 专有字段 |
| --- | --- | --- |
| `rect` | 底、卡、按钮框 | `fill`（颜色或 CSS 渐变）、`radius`、`shadow{x,y,blur,spread,color}`、`stroke` / `strokeWidth` / `strokeStyle`、`stripes` |
| `text` | 文字（自动测量） | `text`、`fontSize`、`fontFamily`、`weight`、`color`、`align`、`lineHeight`、`letterSpacing`、`padding[px,py]`、`background`、`stroke`、`shadow`、`bind` |
| `group` | 容器：子元素 `layout.region` 指向组 id | `clip`、`radius`（裁切圆角） |
| `line` | 连线，端点挂在元素上 | `from` / `to {element, at}`、`color`、`width`、`cap`、`dash`、`curve`、`trim`、`screenWidth`、`connected`、`layer` |
| `path` | 内联 SVG 路径 | `d`、`viewBox`、`fill`、`stroke`、`strokeWidth`、`trim` |
| `image` | 图片 | `src`、`fit: contain | cover`、`radius` |
| `dots` | 背景点阵（CSS 绘制，不生成上千 DOM） | `spacing`、`radius`、`color` |
| `null` | 空对象：没有尺寸、不出画，做连线端点或挂点 | — |

所有盒子元素（除 line）通用：`layout`、`opacity`、`scaleX` / `scaleY`、`rotate`（度）、`origin`（缩放 / 旋转中心，默认 = anchor）、`ignoreMask`、`motion`、`arc`、`arcSide`、`reveal` / `revealFrom`、`bakedReason`。

### 2.1 rect

- 长度单位全是 u：`radius`、`strokeWidth`、`shadow` 的 x / y / blur / spread（语义同 CSS box-shadow）。
- `strokeStyle: "solid" | "dashed" | "dotted"`。
- `stripes{angle, color1, color2, size, size2}`：斜纹底，渲染为 `repeating-linear-gradient(angle, c1 0, c1 size, c2 size, c2 size+size2)`，常用来表示「阻塞 / 待定」。
- `fill` 写 CSS 渐变时是**静态**的：渐变 rect 不能再写 `fill` 颜色节点（会报错）；要变色就叠一层纯色 rect 做透明度过渡。

### 2.2 text

- 测量与渲染用同一份字体参数；`lineHeight` 是字号倍率（默认 1.3），`letterSpacing` 单位 u。
- 写了 `width` / `height` 是固定框，不写则按测量结果定框；`padding` + `background` + `stroke` 给文字加底框，自动尺寸 = 测量值 + padding + 边框。
- `bind: "camera.zoom%"`：实时显示相机缩放百分比。
- **最小字号**：屏幕实际字号（`fontSize × 1080 × 相机缩放 × 组缩放`）不小于 14 px；`check_scene` 低于 13 px 就警告（见 [05](./05-检查器-现场演示与场景构建.md)）。

### 2.3 group

- 必须写 `width` 和 `height`；只能引用在它之前声明的组。
- 子元素矩阵 = 父矩阵 × 自己（位移、缩放、旋转都继承），透明度逐级相乘。**整体缩放连带子文字同缩**——不要把缩放写成框的宽高。
- 组的 `width` / `height` 节点会让子元素按百分比布局重新解算（卡片变形、内部文字跟着重排）。
- `clip: true`（可配 `radius`）：后代按组框裁切，嵌套裁切取交集；组或子元素带旋转时报错（只支持轴对齐）。

### 2.4 line

- 端点 `{ element, at }`：`at` 是该元素框内中心坐标 `[-1, 1]`；挂在 `null` 空对象上就能「一个点驱动多条线」。
- `curve: "horizontal" | "vertical"`：三次贝塞尔，`M a C a.x+h,a.y  b.x−h,b.y  b`，`h = clamp(dx × curveRatio, curveMin, curveMax)`，默认 `0.5`、`33 px`、`240 px`；`vertical` 同理用 dy。不写 = 直线。
- `trim` 0..1：按弧长截取（生长动画）；`dash: [段长, 间隔]`（u）；`cap: butt | round | square`。
- `width` 单位 u（`px(3)` ≈ 3 px）；`screenWidth: true` 时线宽在屏幕上保持恒定，不随相机缩放。
- `connected: false` 时整条线不画；配合 `connected` 节点 + `trim` 节点可以做「断开 → 重新长出来」。
- `layer: under | world | screen`：不写时取「最少例外」——两端同层就用该层；一端在 screen 就用 screen（世界端按当前相机投影）。跨层推荐两端各挂一个空对象。

### 2.5 path / image / dots / null

- `path`：`viewBox` 内的 SVG 路径按元素框缩放；描边宽度不随缩放变化；`trim` 可做描出。
- `image`：`fit: contain | cover`，`radius` 圆角；宽高可以被节点驱动。
- `dots`：在框内铺满点阵，默认 `motion: "bound"`。
- `null`：只有 `layout.region / x / y / anchor`，不能写宽高；可被 x / y / scale / motionPath 驱动。

## 3. 节点（cue）

```json
{ "at": "t04.50", "target": "card", "property": "opacity", "duration": 0.5, "to": 1, "ease": "ease-out" }
```

- `at` 是时间表里的锚点名，秒数登记在 `<name>-timing.json`（见 [05 §4](./05-检查器-现场演示与场景构建.md)）。
- **可动画属性**：

| 属性 | 适用 | 说明 |
| --- | --- | --- |
| `opacity`、`scale`、`scaleX`、`scaleY`、`rotate` | 盒子元素 | rotate 单位为度 |
| `x`、`y`、`width`、`height` | 盒子元素 | 单位必须与声明一致（全 u 或全 %） |
| `motionPath` | free 元素 | `path{curve: linear | quadratic | cubic, points}`，按弧长匀速，缓动作用在弧长进度上 |
| `trim` | line、path | 0..1 |
| `reveal` | 盒子元素（组、空对象除外） | 0..1 擦出，`revealFrom` 定方向 |
| `fill` / `color` / `background` / `strokeColor` | rect·path / text·line / text / 有 stroke 的元素 | 颜色插值 |
| `text` | text | 瞬时替换（duration 0），已在准备阶段测量所有变体 |
| `connected` | line | 瞬时开关 |
| `zoom`、`target.*`、`position.*`、`approach.*` | camera | 见 [04](./04-相机-弧线跟随与双节点透视.md) |

- **缓动 `ease`**：命名值只有 `linear`、`ease`、`ease-in`、`ease-out`、`ease-in-out`、`sine-in-out`；精确曲线用 `{type:"cubicBezier",x1,y1,x2,y2}`（x 在 [0,1]，y 可过冲）；回弹用 `{type:"spring",stiffness,damping,mass}`（按时长归一化，结束时刚好到位）；逐格用 `{type:"steps",count,position}`。
- **接管规则**：新节点触发时从「当前实际值」出发，而不是从上一个声明值；所以重叠的节点可以无缝接力。
- 同一元素、同一时刻、同一时长的 `x` 与 `y` 合成一条运动（free 元素走弧线，见 [03](./03-运动角色与空对象.md)），两轴 `ease` 必须相同。

## 4. 准备阶段的逐帧检查

`prepareProject` 在每个节点起止时刻之外，还按 fps（默认 30）逐帧求值整条时间线：

- 元素越出所属区域、贝塞尔 / spring 中途过冲越界 → 报「t s：… 超出所属区域」。
- 线性插值的相机 zoom 被过冲到 ≤ 0 → 报错；`interpolation: "log"` 的 zoom 永远为正。
- 固定宽度的文字被组或 width 节点挤窄时，会在最窄宽度下重新测量，校验固定高度。

## 5. 逐帧轨迹检查 `lintScene`

```js
import { lintScene, lintSummary } from "@silkysite/scene"
const warnings = lintScene(projectDocument, timingMap)
```

- 每条 `target.property` 轨道：连续 ≥ 6 个关键帧且相邻间隔都 ≤ 0.07 s（`run`），或 ≥ 25 个关键帧且间隔中位数 ≤ 0.1 s（`density`），判为「疑似逐帧采样轨迹」。
- 动画应当是少量关键帧 + 缓动曲线；确需逐帧时在节点、元素或相机上写非空 `bakedReason`，警告降级为「已报备」。
- `npm run lint:scene`（`--detail` / `--json`）；`check_scene` 要求 0 条未报备警告。

## 6. 设计规则（写场景时遵守）

- **同元素移动，不做假交叉淡化**：一张卡从 A 到 B，就让同一个元素（或同一个组）移过去、变形过去；不要在 A 淡出一张、在 B 淡入另一张「长得一样」的卡。
- **组整体动**：一组元素一起淡出、移动、缩放时改组，不要把同一个节点复制到每个子元素上。
- **颜色状态变化** 用颜色节点；渐变底只做静态。
